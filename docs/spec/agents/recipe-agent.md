# AI agent ①：食譜推薦

對應 `product-spec.md` MVP 第 2 項。負責解決痛點「選不出來」。

## 觸發時機

使用者輸入食材後（`product-spec.md` MVP 第 1 項）。

## 輸入

- 使用者輸入的食材（一種或多種）
- Food Profile：廚房工具、過敏／飲食限制、預設人數

## 輸出

3–5 道推薦（依可推薦結果彈性，上限 5 道），每道包含：

- 菜名
- 難易度（新手／普通／需要經驗）
- 預估時間
- 所需廚房工具
- 缺料摘要
- 成品標準（`data-model.md` 中 Recipe 的 `finished_dish_standard`，供後續老師與評審使用）

## 業務規則

- 推薦前先依廚房工具、過敏／飲食限制過濾
- 難易度與預估時間依規則判斷，非自由估算：
  - 步驟數量
  - 是否需提前處理（醃製過夜、退冰、發酵）
  - 是否需要判斷「感覺」而非明確數字的動作
  - 是否需要特殊技巧或工具
  - 食材項目數量
  - 時間預估依步驟數＋是否需等待計算，確保同一道菜每次結果一致
- 排序：新手友善優先（難易度低、時間短在前）
- 份量、搭配、步驟需經合理性檢查，避免 AI 幻覺
- 食譜來源：AI 生成，且以指定台灣可靠來源為根據（愛料理 iCook、Cookpad 台灣、楊桃美食網、下廚房）以降低幻覺；不自建食譜資料庫

## 邊界情況

- 食材組合罕見、找不到合適菜色 → 坦白說明，並建議補一項食材或替代方向
- 使用者輸入內容無法辨識為食材 → 提示重新輸入
