# 使用者體驗流程（v2）

> 描述使用者從打開 App 到完成一次料理的完整操作流程。只寫「使用者看到什麼、做什麼、系統回應什麼」，不涉及開發排程（排程見 `docs/roadmap.md`）與技術實作。

## 情境

一個不太會煮飯的人，想吃某個食材，但不知道能做成什麼。

## 流程

### 1. 首次打開 App

- 直接問廚房工具（例如電磁爐、電子鍋、氣炸鍋），不用先填其他資料表單
- 設定完成後進入「輸入食材」畫面

### 2. 輸入食材

- 文字輸入想吃或手上有的食材，例如「我想吃櫛瓜」
- 可一次輸入多種食材

### 3. 首次補問個人化資料（僅第一次）

- 快要拿到推薦結果前，才問過敏／飲食限制、人數
- 非首次使用則跳過，沿用設定

### 4. 查看食譜推薦

- 呈現 3–5 道菜，各附難易度、預估時間、缺料摘要
- 選定一道菜（例：櫛瓜炒蛋）

### 5. 查看缺料清單

- 顯示完整缺料清單（食材、調味料、器具）
- 可標記「我有這個」；備齊後進入料理

### 6. 開始料理

- 備料確認（開始前檢查清單）
- 一步一畫面，依序帶著操作
- 可隨時文字或語音提問
- 需要等待的步驟提供計時
- 卡關時可拍照問「這樣對嗎」

### 7. 完成料理，拍照

- 提示拍照引導（光線、角度、整盤入鏡）

### 8. 查看評分

- 三項分項分數（色彩搭配、擺盤造型、烹調完成度）
- 一個做得好的點、一個下次改進的點
- 註明「照片看不出味道與熟度」

### 9. 收藏與作品集

- 收藏食譜
- 完成的料理存入作品集
- 可選擇再煮下一道，回到步驟 2
